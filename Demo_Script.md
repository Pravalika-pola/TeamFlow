# TeamFlow Demo Script

Hello,

My name is Pravalika Pola, and this is my TeamFlow Project Management System developed using React, Node.js, Express.js, and SQLite.

The application allows users to efficiently manage projects and tasks.

First, on the dashboard, we can see the project statistics, including total projects, total tasks, completed tasks, and overall progress.

Next, I will create a new project by entering the project name and description.

After creating the project, it appears immediately in the project list.

Inside the project, I can add tasks by entering a task title, selecting a priority, and choosing a due date.

Each task can be updated by changing its status from "To Do" to "In Progress" or "Done".

The dashboard automatically updates to reflect completed tasks and overall progress.

Users can also edit or delete projects and tasks.

The search feature allows users to quickly find projects.

This application follows a full-stack architecture where the React frontend communicates with the Express backend through REST APIs, and all project data is stored in a SQLite database.

Thank you for watching my TeamFlow demonstration.
